You are given the following information to evaluate the RL policy's performance during the task.

## Task Description

Use the Shadow Hand's fingers to rotate a cube held in the palm until its
orientation matches a target orientation, from state observations. Reach the
goal pose without dropping the cube, then keep reaching freshly sampled target
orientations, achieving as many consecutive successes as possible.

## Verifying Success
To determine a successful rotation, the target orientation is shown by a floating reference cube in the scene. 
This target only updates to a new orientation once the in-hand cube exactly matches it. If the cube never changes throughout the video,
the agent has not achieved a single success in that clip - even if the in-hand cube looks close. 
You should count the number of times the floating cube updates to get the number of successful rotations.

## Desired Behaviour
The policy should exhibit controlled, smooth, and continuous multi-finger contact to reorient the object directly toward the goal pose. This should occur for most of the rollout.
Some desired behaviours are as follows:
- **Stable In-Hand Manipulation:** Maintained, purposeful contact between the fingertips and the object surface during rotation.
- **Active Goal Progress:** Continuous physical engagement that actively moves the cube toward the target pose without stalling or idling.
- **Controlled Dynamics:** Smooth actuation without high-frequency oscillations, unnatural flicks, or reliance on sudden impacts.
- **Object Containment:** Secure grasp containment within the hand envelope across all orientation changes.

## Deviations to flag
Tag these if they occur at any point, even briefly. 
- **Jitter / oscillations** Rapid, micro-vibrational joint motion instead of smooth actuation. Compare consecutive frames for oscillation.
- **Loss of control / Tossing:** The hand imparts force (flicks, tosses, or slaps) to launch the object airborne or away, breaking finger contact, but usually stays near/in the hand.
- **Passive Stalling / Static Hold:** Freezing in a static grip to collect passive rewards without making active progress toward the goal orientation.
- **Interpenetration / Mesh Clipping:** Unphysical clipping or penetration between the fingertips and the object geometry.
- **Grasp Failure / Dropping:** The cube fully leaves the hand and reappears at a reset pose.
